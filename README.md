# اپلیکیشن اندروید مدیریت بازرگانی و انبارداری (myCRM Mobile)

این نرم‌افزار، نسخه کاملاً بومی و آفلاین سیستم مدیریت بازرگانی و انبارداری است که با فریم‌ورک **Flutter** و به زبان **Dart** پیاده‌سازی شده است. طراحی این اپلیکیشن کاملاً فلت، مدرن، با تقویم هجری شمسی، پشتیبانی کامل از چینش راست به چپ (RTL) و اعداد فارسی بوده و هماهنگی ۱۰۰٪ با نسخه وب دارد.

---

## ویژگی‌های اصلی

### ۱. عملکرد کاملاً آفلاین (Offline-First)
- بدون نیاز به اینترنت و بدون اتصال به سرور خارجی
- ذخیره‌سازی داده‌ها در حافظه محلی گوشی با معماری ایمن و فوق سریع

### ۲. همگام‌سازی و انتقال دیتابیس با نسخه تحت وب (JSON Sync)
- **استخراج (Export JSON):** خروجی گرفتن از کل اطلاعات (فاکتورها، کالاها، مشتریان و تنظیمات) در قالب فایل JSON استاندارد
- **وارد کردن (Import JSON):** خواندن فایل‌های بکاپ نسخه وب (`http://localhost:3000/`) بدون کوچک‌ترین مغایرت در فیلدها و اطلاعات
- قابلیت کپی/چسباندن متن JSON از کلیپ‌بورد برای مواقعی که انتقال فایل مقدور نیست

### ۳. داشبورد مدیریتی فلت و جذاب
- کارت‌های شاخص‌های کلیدی عملکرد (KPI):
  - جمع کل فروش نقدی و نسیه
  - بهای تمام‌شده و سود ناخالص فروش به همراه درصد حاشیه سود
  - ارزش ریالی موجودی کل انبار
  - مجموع خریدهای انبار
- هشدار خودکار کالاهای رو به اتمام (کسری موجودی)
- نمایش زنده آخرین فاکتورهای ثبت شده با وضعیت پرداخت

### ۴. سیستم پیشرفته مدیریت انبار و کالاها
- محاسبه چندسطحی بسته‌بندی: **کارتن**، **بسته**، **دانه**، و **برگی**
- نمایش دقیق موجودی به صورت تفکیک‌شده (مثلاً: «۵ کارتن و ۲۰ دانه»)
- امکان ثبت کالای فله / بدون بسته‌بندی
- مدیریت قیمت خرید، قیمت فروش، و **قیمت روی جلد (مصرف‌کننده)**
- دکمه **شارژ سریع موجودی انبار** بدون نیاز به ویرایش کل کالا
- دسته‌بندی موضوعی کالاها با فیلتر فوری

### ۵. صدور و چاپ فاکتور (خرید و فروش)
- صدور فاکتور فروش برای مشتریان
- صدور فاکتور خرید و ورود بار برای تامین‌کنندگان
- محاسبه خودکار تعداد کل دانه از روی کارتن‌ها و دانه اضافه
- محاسبه سود ناخالص هر ردیف و کل فاکتور
- تخفیف، مالیات و هزینه‌های جانبی
- وضعیت پرداخت: نقدی (تسویه)، نسیه (بدهکار)، بیعانه (پرداخت بخشی)
- **حالت پیش‌نویس (Draft):** ثبت فاکتور بدون کسر یا اضافه شدن به موجودی انبار
- **همگام‌سازی زنده موجودی:** کسر خودکار از انبار هنگام صدور فاکتور فروش، و شارژ خودکار انبار در فاکتور خرید
- بازگشت خودکار موجودی به انبار در صورت ویرایش یا حذف فاکتور
- نمایش و چاپ فاکتور رسمی تجاری با سربرگ، مهر، امضا و قیمت مصرف‌کننده
- امکان اشتراک‌گذاری متن خلاصه فاکتور در پیام‌رسان‌ها (تلگرام، واتساپ، پیامک)

## نحوه ران و نصب روی گوشی اندروید

### ۱. پیش‌نیازها
- نصب بودن **Flutter SDK** (نسخه ۳ به بالا)
- فعال بودن حالت توسعه‌دهنده (Developer Options) و USB Debugging روی گوشی اندروید

### ۲. دریافت پکیج‌ها
ترمینال را در مسیر این پوشه باز کرده و دستور زیر را اجرا نمایید:
```bash
cd android_app
flutter pub get
```

### ۳. اجرای مستقیم روی گوشی یا شبیه‌ساز
گوشی را با کابل به کامپیوتر متصل کرده و دستور زیر را بزنید:
```bash
flutter run
```

### ۴. ساخت فایل خروجی نصبی (APK نهایی)
جهت دریافت فایل `.apk` برای نصب مستقیم روی هر گوشی اندرویدی:
```bash
flutter build apk --release
```
فایل نهایی در مسیر زیر تولید می‌شود:
`build/app/outputs/flutter-apk/app-release.apk`

## سناریوی استفاده بیرون و همگام‌سازی با نسخه تحت وب

1. وقتی بیرون از مغازه یا انبار هستید، فاکتورهای فروش یا خریدهای بار جدید را در اپلیکیشن موبایل ثبت می‌کنید.
2. موجودی انبار گوشی بلافاصله کسر یا اضافه می‌شود.
3. در تب **تنظیمات** گوشی، دکمه **«استخراج دیتابیس (Export JSON)»** را لمس کرده و فایل را در حافظه گوشی ذخیره می‌کنید (یا به تلگرام/بلوتوث خود می‌فرستید).
4. در کامپیوتر، وارد نسخه وب برنامه (`http://localhost:3000/`) شده، به بخش **پشتیبان‌گیری** بروید و روی **«بارگذاری فایل پشتیبان»** کلیک کنید و فایل استخراج‌شده از گوشی را انتخاب فرمایید.
5. تمام فاکتورها، تغییرات موجودی و کالاها فوراً روی وب قرار می‌گیرند — بدون نیاز به حتی ۱ بایت اینترنت!
